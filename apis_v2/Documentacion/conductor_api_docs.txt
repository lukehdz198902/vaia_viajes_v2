1. POST /Registrar
================================================================================
Registra un nuevo conductor en el sistema.

REQUEST (JSON body)
  idCompania         SMALLINT   Requerido   ID de la compania (ej: 1)
  nombre             VARCHAR    Requerido   Nombre(s) del conductor (max 50)
  appaterno          VARCHAR    Requerido   Apellido paterno (max 50)
  apmaterno          VARCHAR    Opcional    Apellido materno (max 50)
  correo             VARCHAR    Requerido   Correo electronico (max 100)
  codigopaistel      VARCHAR    Opcional    Prefijo telefonico (def: '+52', max 15)
  telefono           VARCHAR    Requerido   Telefono a 10 digitos (max 30)
  googlekey          VARCHAR    Requerido   Token FCM para notificaciones push
  account            VARCHAR    Requerido   Nombre de cuenta de usuario (max 50)
  pass               VARCHAR    Requerido   Contrasena en texto plano (se hashea SHA256)
  idiomapreferido    SMALLINT   Opcional    ID del idioma (NULL)
  fechanacimiento    DATE       Opcional    Fecha de nacimiento (YYYY-MM-DD, NULL)
  genero             CHAR(1)    Opcional    Genero M/F/O (NULL)

NOTAS:
  - El campo 'pass' se convierte a SHA256 antes de almacenarse.
  - El campo 'idCompania' y 'googlekey' son obligatorios en el SP.

RESPONSE (200 OK)
  [
    {
      "id": 3,              // INT - Nuevo ID del conductor creado (>0 = exito)
      "mensaje": "Registro exitoso"
    }
  ]

CODIGOS DE RESPUESTA (id)
   3           Registro exitoso (id > 0)
  -1           La cuenta de usuario ya existe
  -2           El correo ya esta registrado
  -3           El telefono ya esta registrado
  -99          Error interno del servidor (ver mensaje)

2. POST /IniciarSesion
================================================================================
Inicia sesion para un conductor registrado.

REQUEST (JSON body)
  account            VARCHAR    Requerido   Usuario o correo electronico (max 50)
  pass               VARCHAR    Requerido   Contrasena en texto plano (se hashea SHA256)
  googlekey          VARCHAR    Opcional    Token FCM para notificaciones push (NULL)
  googlekeyso        VARCHAR    Opcional    SO del dispositivo (android/ios, max 100)
  dispositivoinfo    VARCHAR    Opcional    Info del dispositivo (max 500)
  sistemaoperativo   VARCHAR    Opcional    SO (iOS/Android, max 100)
  ipaddress          VARCHAR    Opcional    Direccion IP (max 50)
  useragent          VARCHAR    Opcional    User agent (max 500)

NOTAS:
  - Busca por account (coincide con account O correo) y pass hasheada.
  - Genera automaticamente un uuidsesion (NEWID()).
  - Actualiza googlekey y googlekeyso en el registro del conductor.
  - Inserta en tbhistorialconexionesconductor y tbsesionusuario.
  - Si el conductor esta bloqueado, devuelve error.

RESPONSE (200 OK) - Exito
  [
    {
      "id": 1,
      "idcompania": 1,
      "nombre": "Carlos",
      "appaterno": "Martinez",
      "apmaterno": "Gomez",
      "correo": "carlos@correo.com",
      "correoconfirmado": false,
      "codigopaistel": "+52",
      "telefono": "5511111111",
      "telefonoconfirmado": false,
      "fotoperfil": "",
      "account": "carlosmtz",
      "bloqueado": false,
      "uuidsesion": "GUID-aqui",
      "mensaje": "Inicio de sesion exitoso"
    }
  ]

CODIGOS DE RESPUESTA (id)
  -1           Credenciales invalidas o cuenta bloqueada
  -99          Error interno del servidor

5. POST /ActualizarPerfil
================================================================================
Actualiza datos del perfil del conductor. Solo envia los campos a modificar.

REQUEST (JSON body)
  idConductor        INT        Requerido   ID del conductor
  nombre             VARCHAR    Opcional    Nuevo nombre (max 50)
  appaterno          VARCHAR    Opcional    Nuevo apellido paterno (max 50)
  apmaterno          VARCHAR    Opcional    Nuevo apellido materno (max 50)
  fotoperfil         VARCHAR    Opcional    Foto en base64 (MAX)
  idiomapreferido    SMALLINT   Opcional    ID del idioma
  fechanacimiento    DATE       Opcional    Fecha de nacimiento (YYYY-MM-DD)
  genero             CHAR(1)    Opcional    Genero M/F/O
  notasadicionales   VARCHAR    Opcional    Notas adicionales (max 500)

NOTAS:
  - Usa ISNULL en SQL, solo actualiza campos no NULL.
  - Si el conductor no existe (activo=1), devuelve error.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Perfil actualizado"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Conductor no encontrado
   1           Perfil actualizado

6. POST /CambiarPassword
================================================================================
Cambia la contrasena del conductor.

REQUEST (JSON body)
  idConductor        INT        Requerido   ID del conductor
  passActual         VARCHAR    Requerido   Contrasena actual (se hashea SHA256)
  pass               VARCHAR    Requerido   Nueva contrasena (se hashea SHA256)

NOTAS:
  - El campo 'passActual' se compara con el hash almacenado.
  - El campo 'pass' es la nueva contrasena (se renombra a 'passNuevo' internamente).
  - Ambos se convierten a SHA256 antes de procesar.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Contrasena actualizada"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Contrasena actual incorrecta
   1           Contrasena actualizada

REQUEST (JSON body)

      "resultado": 1,
      "mensaje": "Estatus actualizado"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Estatus invalido
   1           Estatus actualizado

10. POST /IniciarViaje
================================================================================
Inicia el viaje una vez que el pasajero aborda la unidad.

REQUEST (JSON body)
  idConductor        INT        Requerido   ID del conductor
  idServicio         BIGINT     Requerido   ID del servicio
  codigoInicio       VARCHAR    Requerido   Codigo de inicio proporcionado por el pasajero (max 20)
  lat                VARCHAR    Opcional    Latitud de inicio (max 50)
  lng                VARCHAR    Opcional    Longitud de inicio (max 50)

NOTAS:
  - Valida que el codigoInicio coincida con el generado para el servicio.
  - Cambia estatus del servicio a 'En Viaje'.
  - Establece servicioiniciado=1 y fechaservicioiniciado=GETDATE().
  - Registra la ubicacion de inicio si se proporciona.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Viaje iniciado"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Codigo de inicio invalido
  -2           El servicio no esta en estatus valido
   1           Viaje iniciado

11. POST /FinalizarViaje
================================================================================
Finaliza el viaje cuando se llega al destino.

REQUEST (JSON body)
  idConductor        INT        Requerido   ID del conductor
  idServicio         BIGINT     Requerido   ID del servicio
  lat                VARCHAR    Opcional    Latitud de destino (max 50)
  lng                VARCHAR    Opcional    Longitud de destino (max 50)
  rd_m               INT        Opcional    Distancia real recorrida en metros
  rd_s               INT        Opcional    Duracion real en segundos
  polylineruta       VARCHAR    Opcional    Polyline de la ruta seguida (MAX)
  puntosruta         VARCHAR    Opcional    Puntos de ruta en JSON (MAX)

NOTAS:
  - Cambia estatus del servicio a 'Finalizado'.
  - Establece llegoasudestino=1 y fechallegoasudestino=GETDATE().
  - Cambia estatus del conductor a 'Disponible'.
  - Si se proporciona rd_m/rd_s, actualiza la distancia y duracion reales.
  - Al finalizar, se activa la pantalla de calificacion para el pasajero.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Viaje finalizado"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Servicio no valido o no activo
   1           Viaje finalizado correctamente

21. POST /ReportarIncidente
================================================================================
Reporta un incidente relacionado con un servicio desde la app del conductor.

REQUEST (JSON body)
  idServicio         BIGINT     Requerido   ID del servicio
  idConductor        INT        Requerido   ID del conductor
  idTipo             INT        Requerido   ID del tipo de incidente:
                                               1 = Problema con el Conductor
                                               2 = Problema con el Pasajero
                                               3 = Problema con la Unidad
                                               4 = Problema de Pago
                                               5 = Problema de Ruta
                                               6 = Problema de Seguridad
                                               7 = Queja General
  desc               VARCHAR    Requerido   Descripcion del incidente (MAX)
  so                 VARCHAR    Opcional    SO del dispositivo (max 100)
