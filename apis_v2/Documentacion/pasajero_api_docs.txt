1. POST /Registrar
================================================================================
Registra un nuevo pasajero en el sistema.

REQUEST (JSON body)
  idCompania         SMALLINT   Requerido   ID de la compania (ej: 1)
  nombre             VARCHAR    Requerido   Nombre(s) del pasajero (max 50)
  appaterno          VARCHAR    Requerido   Apellido paterno (max 50)
  apmaterno          VARCHAR    Requerido   Apellido materno (max 50)
  correo             VARCHAR    Requerido   Correo electronico (max 100)
  codigopaistel      VARCHAR    Opcional    Prefijo telefonico (def: '+52', max 15)
  telefono           VARCHAR    Requerido   Telefono a 10 digitos (max 30)
  googlekey          VARCHAR    Requerido   Token FCM para notificaciones push
  account            VARCHAR    Requerido   Nombre de cuenta de usuario (max 50)
  pass               VARCHAR    Requerido   Contrasena en texto plano (se hashea SHA256)
  idiomapreferido    SMALLINT   Opcional    ID del idioma (NULL)
  fechanacimiento    DATE       Opcional    Fecha de nacimiento (YYYY-MM-DD, NULL)
  genero             CHAR(1)    Opcional    Genero M/F/O (NULL)

NOTAS:
  - El campo 'pass' se convierte a SHA256 antes de almacenarse.
  - El campo 'idCompania' y 'googlekey' son obligatorios en el SP.

RESPONSE (200 OK)
  [
    {
      "id": 5,              // BIGINT - Nuevo ID del pasajero creado (>0 = exito)
      "mensaje": "Registro exitoso"
    }
  ]

CODIGOS DE RESPUESTA (id)
   5           Registro exitoso (id > 0)
  -1           La cuenta de usuario ya existe
  -2           El correo ya esta registrado
  -3           El telefono ya esta registrado
  -99          Error interno del servidor (ver mensaje)

2. POST /IniciarSesion
================================================================================
Inicia sesion para un pasajero registrado.

REQUEST (JSON body)
  account            VARCHAR    Requerido   Usuario o correo electronico (max 50)
  pass               VARCHAR    Requerido   Contrasena en texto plano (se hashea SHA256)
  googlekey          VARCHAR    Opcional    Token FCM para notificaciones push (NULL)
  googlekeyso        VARCHAR    Opcional    SO del dispositivo (android/ios, max 100)
  dispositivoinfo    VARCHAR    Opcional    Info del dispositivo (max 500)
  sistemaoperativo   VARCHAR    Opcional    SO (iOS/Android, max 100)
  ipaddress          VARCHAR    Opcional    Direccion IP (max 50)
  useragent          VARCHAR    Opcional    User agent (max 500)
  esLoginGoogle      BIT        Opcional    Flag de login con Google (def: 0)
  googleuserid       VARCHAR    Opcional    ID de usuario de Google (max 255)

NOTAS:
  - Si esLoginGoogle=1 y googleuserid no es NULL, busca por googleuserid.
  - En caso contrario, busca por account (coincide con account O correo) y pass.
  - Genera automaticamente un uuidsesion (NEWID()).
  - Actualiza googlekey y googlekeyso en el registro del pasajero.
  - Inserta en tbhistorialconexionespasajero y tbsesionusuario.

RESPONSE (200 OK) - Exito

      "apmaterno": "Lopez",

      "correoconfirmado": false,
      "codigopaistel": "+52",
      "telefono": "5512345678",
      "telefonoconfirmado": false,
      "fotoperfil": "",
      "account": "juanperez",
      "requierefacturacion": false,
      "bloqueado": false,
      "eslogueadocongoogle": false,
      "googleuserid": null,
      "fotourlgoogle": null,
      "metodopagopreferido": null,
      "idiomapreferido": null,
      "fechanacimiento": null,
      "genero": null,
      "metodopago": null,
      "idioma": null,
      "uuidsesion": "GUID-aqui",
      "mensaje": "Inicio de sesion exitoso"
    }
  ]

CODIGOS DE RESPUESTA (id)
  -1           Credenciales invalidas o cuenta bloqueada
  -99          Error interno del servidor

4. POST /ActualizarPerfil
================================================================================
Actualiza datos del perfil del pasajero. Solo envia los campos a modificar.

REQUEST (JSON body)
  idPasajero         BIGINT     Requerido   ID del pasajero
  nombre             VARCHAR    Opcional    Nuevo nombre (max 50)
  appaterno          VARCHAR    Opcional    Nuevo apellido paterno (max 50)
  apmaterno          VARCHAR    Opcional    Nuevo apellido materno (max 50)
  fotoperfil         VARCHAR    Opcional    Foto en base64 (max)
  idiomapreferido    SMALLINT   Opcional    ID del idioma
  fechanacimiento    DATE       Opcional    Fecha de nacimiento (YYYY-MM-DD)
  genero             CHAR(1)    Opcional    Genero M/F/O
  notasadicionales   VARCHAR    Opcional    Notas adicionales (max 500)

NOTAS:
  - Usa ISNULL en SQL, solo actualiza campos no NULL.
  - Si el pasajero no existe (activo=1), devuelve error.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Perfil actualizado"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Pasajero no encontrado
   1           Perfil actualizado

6. POST /CambiarPassword
================================================================================
Cambia la contrasena del pasajero.

REQUEST (JSON body)
  idPasajero         BIGINT     Requerido   ID del pasajero
  passActual         VARCHAR    Requerido   Contrasena actual (se hashea SHA256)
  pass               VARCHAR    Requerido   Nueva contrasena (se hashea SHA256)

NOTAS:
  - El campo 'passActual' se compara con el hash almacenado.
  - El campo 'pass' es la nueva contrasena (se renombra a 'passNuevo' internamente).
  - Ambos se convierten a SHA256 antes de procesar.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Contrasena actualizada"
    }
  ]

CODIGOS DE RESPUESTA (resultado)
  -1           Contrasena actual incorrecta
   1           Contrasena actualizada

7. POST /EnviarCodigoVerificacion
================================================================================
Envia un codigo de verificacion de 6 digitos al telefono del pasajero.

REQUEST (JSON body)
  codigopaistel      VARCHAR    Requerido   Prefijo telefonico (max 15)
  telefono           VARCHAR    Requerido   Numero de telefono (max 30)

NOTAS:
  - Genera un codigo aleatorio de 6 digitos: CAST(100000+RAND()*899999 AS INT).
  - El codigo expira a los 10 minutos (DATEADD(MINUTE,10,GETDATE())).
  - Inactiva codigos previos del mismo telefono.
  - Inserta en tbpasajerocodigos.
  - En desarrollo/produccion, se debe enviar por SMS/WhatsApp.

RESPONSE (200 OK)
  [
    {
      "resultado": 1,
      "mensaje": "Codigo enviado",
      "codigoverificacion": "483729"   // Solo visible en desarrollo
    }
  ]

NOTA: El campo 'codigoverificacion' en la respuesta solo debe usarse
      en ambiente de desarrollo. En produccion NO debe exponerse.

9. POST /ValidarCodigoPromocional
================================================================================
Valida un codigo promocional contra el pasajero y el monto del viaje.

REQUEST (JSON body)
  codigo             VARCHAR    Requerido   Codigo promocional (max 100)
  idPasajero         BIGINT     Requerido   ID del pasajero
  montoViaje         DECIMAL    Opcional    Monto del viaje (def: 0)

VALIDACIONES (internas)
  - Codigo existe y activo
  - No expirado (vigentehasta)
  - Vigente desde (validodesde)
  - Limite de usos no alcanzado
  - Usuario unico (si aplica)
  - Monto minimo de viaje (si aplica)

RESPONSE (200 OK)
  [
    {
      "valido": true,
      "mensaje": "Codigo valido",
      "montodescuento": 25.00,
      "esporcentaje": false,
      "idcodigopromo": 1
    }
  ]

CAMPOS DE RESPUESTA
  valido             BIT             true = valido, false = invalido
  mensaje            VARCHAR(500)    Descripcion del resultado
  montodescuento     DECIMAL(18,2)   Monto del descuento calculado
  esporcentaje       BIT             true = % descuento, false = monto fijo
  idcodigopromo      INT             ID del codigo promo (NULL si invalido)

10. POST /SolicitarServicio
================================================================================
Solicita un nuevo servicio de viaje.

REQUEST (JSON body)
  idPasajero           BIGINT     Requerido   ID del pasajero
  idCompania           SMALLINT   Requerido   ID de la compania (ej: 1)
  dirOrigen            VARCHAR    Requerido   Direccion de origen (max 300)
  latOrigen            VARCHAR    Requerido   Latitud de origen (max 50)
  lngOrigen            VARCHAR    Requerido   Longitud de origen (max 50)
  dirDestino           VARCHAR    Requerido   Direccion de destino (max 300)
  latDestino           VARCHAR    Requerido   Latitud de destino (max 50)
  lngDestino           VARCHAR    Requerido   Longitud de destino (max 50)
  distanciaMetros      INT        Requerido   Distancia estimada en metros
  idTipoPago           SMALLINT   Requerido   ID tipo de pago:
                                                 1 = Efectivo
                                                 2 = Tarjeta de Credito
                                                 3 = Tarjeta de Debito
                                                 4 = PayPal
                                                 5 = Mercado Pago
                                                 6 = Transferencia
  codigoPromocional    VARCHAR    Opcional    Codigo promocional (max 100)
  so                   VARCHAR    Opcional    SO del dispositivo (max 100)
  tipoviaje            VARCHAR    Opcional    Tipo de viaje (def: 'URBANO')

NOTAS:
  - Calcula el costo usando fn_CalcularCostoViaje.
  - Aplica descuento promocional si se proporciona codigo.
  - La duracion estimada se calcula como distanciaMetros/250*60 (segundos).
  - Inserta en tbservicios con estatus 'Solicitado'.
  - Si el codigo promo es valido, incrementa usosactuales.

RESPONSE (200 OK) - Exito
  [
    {
      "idservicio": 15,            // BIGINT - ID del servicio creado
      "costoestimado": 85.50,      // DECIMAL(18,2) - Costo final
      "distanciametros": 5000,     // INT - Distancia en metros
      "duracionsegundos": 1200,    // INT - Duracion estimada en segundos
      "montodescuento": 0.00,      // DECIMAL(18,2) - Descuento aplicado
      "mensaje": "Servicio solicitado"
    }
  ]

RESPONSE - Error
  [
    {
      "idservicio": -99,
      "mensaje": "Mensaje de error del servidor"
    }
  ]
